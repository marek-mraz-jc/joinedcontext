# controlroom Design Decisions (Better Over Faithful)

- **Canonical `BTreeMap` storage for unknown JSON fields (`controlroom-model`)**: Replaces Grafana's unordered Go `map[string]any` with `BTreeMap<String, Value>` at every schema level so `export(import(f))` is deterministic and byte-stable by construction without losing unknown fields.
- **DNS-pinned outbound guard with IPv4-mapped IPv6 normalization (`controlroom-query`)**: Replaces Grafana's optional `data_source_proxy_whitelist` (which checks hostnames before connect and is vulnerable to DNS rebinding) with a mandatory per-datasource host allow-list that resolves DNS once, rejects loopback/private/link-local/CGNAT/metadata IPv4 and IPv4-mapped IPv6 addresses, and pins the validated socket addresses on the HTTP client.
- **Iterative depth-bounded PromQL & SQL macro/template interpolation (`controlroom-query`)**: Replaces Grafana's raw string replacement for template variables with context-aware escaping (PromQL regex/literal escaping and single-SELECT read-only view verification after comment stripping) so template variables cannot inject query syntax across languages.
- **Hashed 256-bit public dashboard tokens with org/version-bound cache keys (`controlroom-api`, `controlroom-query`)**: Replaces Grafana's plaintext `access_token` column and uncached public queries with SHA-256 hashed tokens compared in constant time, strict rejection of any caller-supplied query/target/expression/variable payload on public endpoints, and a cache key bound to `(org_id, instance_id, dashboard_uid, dashboard_version, panel_id, range_bucket)`.
- **Cryptographic `state_etag` in `plan`/`apply` (`controlroom-import`)**: Replaces blind `overwrite: true` provisioning with a SHA-256 digest of the organization's live dashboard/folder/datasource state embedded in every plan bundle and verified before `apply` (refusing stale plans with exit code 3 / HTTP 409).
- **Single operation registry driving OData 4.01 CSDL, MCP tools, and CLI (`controlroom-model`, `controlroom-api`, `controlroom-mcp`, `controlroom-server`)**: Replaces Grafana's separate REST, gRPC, and provisioning code paths with one declaration table where OData, MCP, and CLI execute the same handler and `Authorizer` check.
